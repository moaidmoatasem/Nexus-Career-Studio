## Goal
Every role shows, in one consistent badge, what the official data says about the employer for the role's country, plus any
Gulf note or reserved-profession warning, and a user who needs sponsorship can hide roles that clearly won't work.

## Prior art to check first
career-ops flags postings that say "no sponsorship"; Nexus already does the same deterministically in
`src/lib/sponsorship.ts` (`scanSponsorship`). Reuse that, do not add AI. JobSync: none found.

## What to build
1. `src/components/VisaBadge.tsx` (new): input = role country (`roleCountry` from `src/lib/visa`), the module's
   `EmployerCheck`, the posting's `scanSponsorship` signal and any `reservedFor` rule (9.2). Shows status, source and date in a
   tooltip, and the quote from the posting. Replaces the inline badge logic in `radar.tsx` (around the "Licensed sponsor /
   Possible sponsor · confirm name / No sponsor match / Outside UK" block). Uses `src/components/ui/badge.tsx` and
   `tooltip.tsx`.
2. `src/lib/data.ts`: generalise `useSponsorSet` to `useEmployerChecks(roles)` that groups by country and calls each module's
   `checkEmployer` once per distinct company, cached by React Query. Keep it batched; no request per card render.
3. Show the badge on Discover (`radar.tsx`), Saved (`saved.tsx`), Today (`today.tsx`) and the daily queue from 6.1.
   `sponsors.tsx` becomes a country picker over the modules (UK default).
4. Filter: 5.1 adds `visa_needed_countries` to each search profile (and retires `profiles.requires_visa`). A role "needs
   sponsorship" when its country is in that list (5.1's `visaNeededFor`). Add a per-profile "hide roles that won't sponsor"
   switch: when on, hide roles whose posting says no sponsorship or right to work required, and order listed employers
   first; "not listed" and `no_data` stay visible but marked.
5. Scores: keep `calculateFitScore` unchanged unless the owner answers the question below; the badge is display only.
6. Text goes through `t()` if 10.4 has merged; otherwise plain English that 10.4 will pick up.
