## Goal
The owner can review every main screen in both directions from one CI run, and a regression that breaks `dir` on the
server is caught automatically.

## Prior art to check first
None found in career-ops or JobSync.

## What to build
1. `src/test/direction.test.ts` (new, Vitest): with the `nexus_lang` cookie `ar`, the root shell renders `lang="ar"` and
   `dir="rtl"`; with `en`, a missing or an invalid cookie, `lang="en"` and `dir="ltr"`. Reuse the server-function and
   `parseLang` code from 10.1 rather than copying it.
2. `e2e/rtl.spec.ts` (new, Playwright): sign up a fresh user the way `e2e/smoke.spec.ts` does (extract the sign-up and
   seed steps to `e2e/helpers/` if both specs need them; the fake AI in `e2e/fake-ai.mjs` stays). Then for `en` and `ar`
   (set the cookie with `context.addCookies`): load `/auth`, `/today`, `/radar`, `/applications`, `/connections`,
   `/settings` and `/vault`, and assert `html[dir]` from the first HTML response (no flash), then take full-page screenshots
   at desktop and a phone viewport (for example `devices["Pixel 7"]`).
3. Also open one dropdown menu, one sheet (the mobile sidebar) and one dialog in Arabic and screenshot them, since those are
   where mirroring bugs show.
4. Screenshots are for human review, not pixel assertions: write them to `test-results/rtl/<lang>-<screen>-<viewport>.png`
   and upload them in `.github/workflows/e2e.yml` with `actions/upload-artifact` next to the existing `playwright-report`
   step. Do not commit images.
5. Add a small automatic check that is not a screenshot: in Arabic, the sidebar's bounding box is on the right half and no
   page has horizontal overflow (`document.documentElement.scrollWidth <= innerWidth`).
