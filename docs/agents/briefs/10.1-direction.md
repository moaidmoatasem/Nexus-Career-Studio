# 10.1 Language setting and page direction

**State:** gate-1 · **Needs:** Gate 1 ticked; Phase 1. First task of Phase 10: 10.2–10.6 all build on it. Order: 10.1 → 10.2 (alone) → 10.3 and 10.4 (in parallel) → 10.5 → 10.6.

**Branch:** `agent/10.1-direction` · **PLAN.md:** [10.1](../../../PLAN.md#phase-10-arabic-first-interface-gate-1)

## Goal
A user can switch the app between English and العربية, and the very first server-rendered paint already has
`<html lang="ar" dir="rtl">`, so there is no left-to-right flash and menus and popovers open on the correct side.

## Prior art to check first
career-ops is a CLI with Arabic modes for documents, not an interface; JobSync: none found. Nothing to reuse here.

## What to build
1. `src/lib/locale.ts` (new, pure): `type Lang = "en" | "ar"`, `LANG_COOKIE = "nexus_lang"`, `parseLang(value)` (anything
   unknown → `"en"`), `dirFor(lang)`. No country logic here; languages are not countries.
2. `src/lib/locale.functions.ts` (new): `getLang` and `setLang` server functions (`createServerFn`) reading and writing the
   cookie with TanStack Start's server cookie helpers (check the exports of the installed `@tanstack/react-start` version,
   for example `getCookie`/`setCookie` from `@tanstack/react-start/server`). Cookie: `Path=/`, `SameSite=Lax`, `Secure` in
   production, one year. No Node built-ins.
3. `src/routes/__root.tsx`: load the language in the root route (`beforeLoad` or `loader`) and render
   `<html lang={lang} dir={dirFor(lang)}>` in the shell (now hard-coded `<html lang="en">`, around line 105). Wrap the app in
   `DirectionProvider` from `@radix-ui/react-direction` (add it with `bun add`, same major as the other `@radix-ui/*`
   packages) and a small `LangContext` exposing `lang`, `dir` and `setLang`. Leave the font links in `head` to 10.3.
4. `src/components/LanguageSwitch.tsx` (new): two options, "English" and "العربية" (each label in its own language), calls
   `setLang` then `router.invalidate()` so the shell re-renders with the new `dir`. Place it in Settings
   (`settings.tsx`) and in the sidebar footer (`SidebarFooter` in `_authenticated/route.tsx`), and on `/auth` if it fits.
5. Do not flip `side` on `src/components/ui/sidebar.tsx` or `sheet.tsx` by hand: 10.2 converts their classes to logical
   ones, after which "left" means "start". Note any broken RTL layouts in the PR for 10.2.
